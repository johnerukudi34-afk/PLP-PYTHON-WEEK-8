# PLP Python Week 8 Toolkit

## What My Toolkit Does

My Python Toolkit is a menu-driven program with three useful tools. It includes a Simple Calculator, a To-Do List, and a Number Checker. The program allows the user to select a tool from the menu and returns to the main menu after each tool is finished.

## Tools Included

1. **Simple Calculator** – Calculates the sum, difference, product, and division of two numbers.
2. **To-Do List** – Allows the user to add, view, and remove tasks.
3. **Number Checker** – Checks whether a number is positive, negative, zero, even, or odd.

## Python Concepts Used

* `while` loops
* `for` loops
* `if`, `elif`, and `else`
* Lists
* `append()` and `pop()`
* User input
* Arithmetic operators
* The modulo `%` operator
* f-strings
* Functions are not required for this project

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run the following command:

```text
python toolkit.py
```

4. Choose a tool by entering its menu number.
5. Choose option `4` to quit the program.

## Reflection

The hardest part of this project was putting all three tools into one menu-driven program. The menu loop was challenging because it had to return after each tool finished. The bug that took the longest to fix was making sure the different choices went to the correct tool. Testing each option helped me understand how `if`, `elif`, and `else` work together. I also learned how a list can change while a program is running by adding and removing tasks. The project helped me become more comfortable with loops, conditionals, lists, and f-strings. With one more week, I would add more tools and improve the menu with more features.
